## Nix daemon packaging follow-up

The daemon installer rejects the Nix package's external helper symlinks with `package link escapes its root`.
The overlay now copies ripgrep and Linux zsh and bubblewrap into the package instead of linking outside it.
The overlay also disables nixpkgs' ripgrep PATH wrapper, which fails the daemon's executable-identity check.
Codex adds its packaged `codex-path` directory to PATH without that wrapper.
The new `package-layout` flake check rejects escaping or directory links, verifies helper executability,
and exercises isolated daemon startup and shutdown.
The check rejects the original macOS package and accepts a copy with materialized helpers.
An isolated daemon installation from that copy with the unwrapped entrypoint starts, reports version 0.159.2, and stops successfully.
The smoke test disables automatic updates and uses a disposable Codex home without touching the user's daemon.
The final unwrapped aarch64-darwin Nix package passes the same daemon start/version/stop check inside the Nix build sandbox.
`nu scripts/check-release.nu` passes again with the new package-layout gate.
All three declared platforms evaluate; Linux execution remains delegated to Linux hosts.
