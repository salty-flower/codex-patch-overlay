## Port

Scheduled auto-release failed from 2026-10-07 onward:
it targets the newest upstream stable tag → `rust-v0.161.0`, then `rust-v0.162.0`, then `rust-v0.162.1` →
`plan-mode-default` no longer applied, which stopped the run before the later patches were checked.
This port goes straight to `rust-v0.162.1`; no overlay release is cut for the two intermediate tags.
Ten of the thirteen patches needed source, fixture, or retirement changes.

`chatgpt-recursion-limit` is retired:
upstream #49706 adds the same `#![recursion_limit = "256"]` to `codex-chatgpt`,
so the carried patch no longer applies.

`plan-mode-default` adds its `ModeKind` schema entry next to upstream's new `MicrophoneChannels` entry.

`timed-queue` drops its copy of the default command-popup snapshot:
upstream #50808 deleted that snapshot test, and no remaining test lists every slash command.

`tui-status-line-command` follows upstream's move of `footer_props`, `footer_mode`, and `custom_footer_height`
into `chat_composer/footer_state.rs`.
The command-row height rule now lives there; the three-way merge had restored stale copies in `chat_composer.rs`.

`editable-enter-queue` keeps its recall handler next to upstream's new turn-input tracing span,
and keeps duplicate client-ID rejection while upstream's steer helper now also returns the root turn ID.
Its submission initializer supplies the new `turn_extension_init` field,
and its recall test asserts the returned root turn ID.
The Daybreak routing fixture generates a fresh client message ID for every independently submitted scenario.

`websocket-reconnect` drops its realtime fixture hunks.
Upstream now gives each affected realtime test a separate startup server for Responses,
so the probe before reuse can no longer take the realtime connection slot those hunks protected.

`codex-rotate` follows upstream's compaction refactor:
manual and auto compaction now receive a captured `StepContext`.
Manual compaction reads the admitted account from that step instead of capturing a second step;
auto compaction still sends the current step's account, not the speculative replacement step's.
Upstream's new enterprise-authorization cleanup during CLI logout loads auth with the rotate helper cleared,
so logout still cannot acquire or refresh a pool account.
App-server logout keeps upstream's enterprise credential lock around the helper-aware logout.
The MCP runtime test unwraps the helper-aware initialization result before inspecting its configuration.
Request-owned auth snapshots copy the captured application network policy as well as the HTTP factory,
following upstream's separation of those fields and preserving revocation after an account switch.

`tui-reasoning-display` supplies the new optional root turn ID in its turn notification fixtures.
`core-test-unused-import` also removes the unused `ReasoningEffort` import from upstream's scenarios suite.

The stable and experimental compressed app-server exports are regenerated from the cumulative patched source.
Compiler-generated workspace-version changes to `Cargo.lock` are excluded from the carried patches.

Nix builds and the development shell share `rust-bin.stable.latest.default`, fixed to Rust 1.99.0 by the locked `rust-overlay` input.
The toolchain patch replaces deprecated atomic update names and makes diverging error macros statements for Rust 1.99.
The CI unit-test job builds `test_stdio_server` before running the new app-server lifecycle fixture that invokes it.
The Nix package applies the manifest's patch stack directly,
matching release tarballs and avoiding nixpkgs' package-specific daemon-default patch with a different path-strip convention.

The remaining patches rebase on context only.
