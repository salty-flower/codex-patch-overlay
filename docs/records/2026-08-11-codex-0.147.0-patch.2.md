# codex-0.147.0-patch.2

## Source

- Upstream: `openai/codex@rust-v0.147.0`
- Upstream SHA: `be6e8eac029b183056b7e4402879f15d2c85f61b`
- Patch release: `codex-0.147.0-patch.2`
- Released commit: `ccfe78acbbb4301955df0f1bb84a732e69847098`

## Why

`codex-0.147.0-patch.1` predates `release.yml` building `codex-code-mode-host`.
Upstream 0.147.0 promoted `features.code_mode_host` to stable with
`default_enabled: true` and removed the in-process code-mode runtime, so a
package without that binary makes code mode fail closed with
`Code Mode is unavailable because failed to spawn code-mode host …`.

## Artifact Provenance

Assembled by hand instead of built by CI, to avoid a full v8 rebuild for
binaries that would be equivalent:

- `bin/codex`, `bin/codex-responses-api-proxy`: the CI-built binaries from the
  `codex-0.147.0-patch.1` artifacts, unchanged.
- `bin/codex-code-mode-host`: upstream's own release binary from
  `openai/codex@rust-v0.147.0`
  (`codex-code-mode-host-<target>.tar.gz`), renamed into `bin/`.
- `manifest.toml`: taken from the released commit, so it records `patch.2`.

Compatibility of that mix was checked, not assumed:

- No enabled patch touches `codex-rs/code-mode*`, `codex-rs/code-mode-host`, or
  `codex-rs/install-context`; the only `codex-protocol` change
  (`auto-thread-name`) adds an `EventMsg` variant.
- The host crate's sources at `rust-v0.147.0` never reference `codex_protocol`.
- Both sides come from the same upstream tag and negotiate
  `ClientHello`/`HostHello` `ProtocolVersion::V1`.

Verified locally before publishing: `bin/codex --version` reports
`codex-cli 0.147.0`, `bin/codex-code-mode-host --help` runs, the host binary is
an arm64 Mach-O signed by upstream, and machine-state's `packages/codex-bin.nix`
installs all three binaries from the darwin tarball.

## Gate

- `nix flake check` covers the released commit through the `check` workflow run
  for `ccfe78a`.
- The tag-triggered `release.yml` run was cancelled on purpose: a CI rebuild
  would have overwritten the hand-uploaded assets and changed their SHA-256,
  breaking downstream pins.
