## Reasoning display

| Setting | Behavior |
| --- | --- |
| `status-only` | Default upstream status row and expanded transcript behavior |
| `persistent` | Live summary preview and completed summaries in ordinary scrollback, including restored history |
| `hidden` | Suppressed summaries and generic working status |

`show_raw_agent_reasoning` independently controls raw reasoning in all three modes.
`model_reasoning_summary` must request summaries from a supporting model; the display setting itself does not change model requests.

Live previews use their own history cell and preserve the active tool's identity.
If a summary completes while a tool still runs, the tool remains at the live tail and continues receiving output and completion updates.
Completed tool groups retain ordinary history insertion order.
Authoritative completion replaces partial streamed content; an absent completion body retains the received stream.
Summary item IDs prevent stale events and duplicate completion from adding another copy.
Safety buffering hides provisional previews and restores them when waiting ends.
History pagination, transcript export, and local or remote resume use the configured display mode.
