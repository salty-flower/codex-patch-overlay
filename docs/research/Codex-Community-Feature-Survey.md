# Codex Community Feature Survey

## Patchability Split

| Feature | Patchability | Notes |
| --- | --- | --- |
| Stream reasoning summaries | medium | TUI-local port preferred over full PR replay |
| Symlinked skills | low | Loader-only change |
| Notification sound | low | TUI notification path |
| WebP image input | low | Image dependency and clipboard handling |
| Transcript search | high | Larger TUI navigation surface |
| Directory `@` selection | medium | Touches protocol and composer |
| Sensitive-file exclusion | high | Needs policy design |
| `/undo` or `/rewind` | high | Needs file and session rollback model |
